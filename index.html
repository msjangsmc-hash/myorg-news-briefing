오늘은 원격 침투·정찰 관련 신규 기법이 다수 보고됐다. RedHook 안드로이드 악성코드는 무선 ADB를 악용해 PC 연결 없이 모바일 단말 셸 권한을 탈취하는 변종이 확인됐고, 호주 ACSC는 취약한 CMS·플러그인을 노린 전 세계적 익스플로잇 캠페인 경보를 발령해 패치되지 않은 웹사이트가 표적임을 경고했다. Zimbra Classic 웹클라이언트는 조작된 메일 수신만으로 세션 내 악성코드 실행이 가능한 저장형 XSS 취약점(CVE 미부여)이 발견돼 긴급 업데이트가 권고됐으며, GitHub API를 악용한 유령 계정발 대규모 정찰 캠페인은 공급망 공격·표적 피싱의 전조로 지목됐다. 자체 운영 중인 CMS·웹메일·개발 저장소가 있다면 패치 현황과 이상 접근 로그를 점검할 필요가 있다.

[해외] Zimbra 치명적 취약점 — 조작된 메일로 사용자 세션에서 악성코드 실행 가능
